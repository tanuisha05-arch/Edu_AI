# EduAI – AI Powered Learning Assistant 

 Overview
EduAI is an AI-powered educational web application developed using HTML, CSS, JavaScript, and Google Gemini API. It helps students learn through an AI chatbot, quizzes, and score tracking.



 Features
- AI Tutor using Google Gemini API
- Quiz System with multiple topics
- Easy, Medium, and Hard difficulty levels
- Score & Progress Tracker
- Responsive User Interface



Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Gemini API
- NLP (Natural Language Processing)


 How It Works
text
User → JavaScript → Gemini API → AI Response → Display on Screen
