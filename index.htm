ℹ️ About This Project

AI in Education — Web Application Project

📌 Context

With the rapid growth of digital learning platforms, students increasingly rely on online tools to understand academic concepts. However, many traditional e-learning systems lack real-time interaction and personalized feedback.

By integrating Artificial Intelligence (AI) and Natural Language Processing (NLP) via the Google Gemini API, this web application provides instant responses, generates quizzes, and supports students in understanding educational topics more effectively.

🎯 Objective

  • Provide instant answers to student questions using Google Gemini AI
  • Generate interactive quizzes across multiple CS topics
  • Track student performance and quiz history
  • Improve engagement through a friendly, easy-to-use interface
  • Support personalized learning through topic-based quizzes

⚙️ How the System Works

1
Student types a question through the web interface.
2
Input is sent to Google Gemini API which processes it using NLP.
3
The AI identifies the user's intent and relevant topic area.
4
Gemini generates a clear, accurate, educational response.
5
Quiz questions are generated from a curated knowledge base per topic.
6
The system evaluates answers and calculates the student's score instantly.
7
Feedback and explanations are shown after each question.
8
All quiz results are saved and displayed in the Progress Tracker.

🛠️ Technologies Used

FrontendHTML5, CSS3, JavaScript (Vanilla)
AI / NLP EngineGoogle Gemini API (gemini-2.0-flash)
Quiz SystemKnowledge base — 6 topics, 3 difficulty levels
Progress TrackingJavaScript session-based storage
